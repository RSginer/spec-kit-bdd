# Acceptance Features

- [health.feature](health.feature): Confirms the service reports a healthy status.
- [weekly-todo-capture.feature](weekly-todo-capture.feature): Creates and reviews todos planned for the current week.
- [weekly-todo-maintenance.feature](weekly-todo-maintenance.feature): Updates weekly todo details and completion state.
- [weekly-todo-removal.feature](weekly-todo-removal.feature): Removes obsolete weekly todos while preserving the rest of the list.
